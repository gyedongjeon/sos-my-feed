# SOS My Feed

[English](README.md) | **한국어**

[![Release](https://img.shields.io/github/v/release/gyedongjeon/sos-my-feed)](https://github.com/gyedongjeon/sos-my-feed/releases/latest)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

열어 둔 탭이 너무 많나요? 즐겨 읽는 **뉴스 사이트와 블로그의 RSS·Atom 피드**를 내 컴퓨터에서 모아
읽는 앱입니다. 피드를 구독하면 새 글이 한 목록에 모이고, 글은 앱 안에서 책처럼 넘기며 읽습니다.

[SOS My Language](https://github.com/gyedongjeon/sos-my-language)와 같은 SOS 시리즈입니다.

## 주요 기능
- **구독한 글을 한 목록으로**: 모든 피드의 글을 최신순으로 보거나, 피드 하나의 글만 봅니다.
- **앱 안에서 책처럼 읽기**: 글을 누르면 광고·메뉴·스크립트 없이 본문만 열립니다. [Re:Leaf](https://github.com/gyedongjeon/releaf) 리더처럼 스크롤 대신 페이지로 나뉘고, 한 페이지 또는 두 페이지씩 보며 화면 좌우를 눌러 넘깁니다.
- **내 눈에 맞는 화면**: 배경색 여섯 가지, 글자 크기, 줄 간격, 여백을 고를 수 있습니다.
- **내 컴퓨터에 저장**: 구독 목록, 글, 설정은 내 컴퓨터의 파일 하나에 저장됩니다. 계정도, 외부 서버도 없습니다.
- **19개 언어 화면**: 한국어, 영어, 일본어, 중국어(간체·번체), 스페인어, 프랑스어, 독일어, 이탈리아어, 포르투갈어, 폴란드어, 러시아어, 우크라이나어, 터키어, 베트남어, 태국어, 인도네시아어, 힌디어, 벵골어. 라이트·다크 테마.

## 설치
**Apple Silicon Mac**과 **64비트 Windows**용 설치 파일을 [최신 릴리스](https://github.com/gyedongjeon/sos-my-feed/releases/latest)에서 받을 수 있습니다.

### macOS

1. `.dmg` 파일을 내려받아 열고, 앱을 Applications 폴더로 끌어 넣습니다.
2. Apple 개발자 인증서로 서명하지 않은 앱이라 macOS가 처음에는 실행을 막습니다. 터미널에서 아래 명령을 한 번 실행한 뒤 앱을 엽니다.
   ```bash
   xattr -cr "/Applications/SOS My Feed.app"
   ```
3. 처음 실행할 때 Python과 Python 패키지(패키지 약 20MB)를 내려받습니다. 인터넷 연결이 필요하고 1분쯤 걸릴 수 있습니다.

다른 프로그램은 설치하지 않아도 됩니다.

### Windows
1. `SOS-My-Feed-Setup-<버전>.exe`를 내려받아 실행합니다. 현재 사용자 계정에만 설치되며 관리자 권한이 필요 없습니다.
2. 서명하지 않은 설치 파일이라 "Windows의 PC 보호" 창이 뜹니다. **추가 정보**를 누른 뒤 **실행**을 누릅니다.
3. 처음 실행할 때 Python 패키지를 내려받습니다(Python 자체는 설치 파일에 들어 있습니다).

Windows 앱은 직접 써 보지 못했고 자동화된 검사로만 확인했습니다. 문제가 있으면 이슈로 알려 주세요.

Intel Mac, Linux용 설치 파일은 아직 없습니다. [소스에서 실행](README.md#run-from-source)할 수 있습니다.

## 업데이트
설치한 앱은 열 때마다 새 버전이 있는지 확인합니다. 새 버전이 있으면 알림 창이 뜨고, "Update and Restart"를 누르면(데스크톱 앱의 알림 창은 아직 영어입니다) 앱이 새 버전을 내려받아 스스로 교체한 뒤 다시 열립니다. 구독 목록과 설정은 그대로 유지됩니다. 메뉴의 **SOS My Feed → Check for Updates…**로 직접 확인할 수도 있습니다.

- 앱을 Applications 폴더로 옮기지 않고 실행한 경우 등 스스로 교체할 수 없을 때는 다운로드 페이지를 열어 줍니다.
- Windows에서는 새 버전을 알려 주고 다운로드 페이지를 엽니다. 새 설치 파일을 그대로 실행하면 되고, 데이터는 유지됩니다.

0.2.0까지는 구조가 다른 앱이었습니다(구독 목록을 브라우저에 저장). 스스로 업데이트되지 않고 구독 목록도 옮겨지지 않으므로, 이전 앱을 지우고 새 앱을 설치한 뒤 다시 구독해 주세요.

## 삭제
앱이 저장하거나 내려받는 것(구독 목록과 글, 설정, 실행에 필요한 파일)은 모두 `~/Library/Application Support/SOS My Feed/` 폴더 하나에 있습니다(Windows는 `%APPDATA%\SOS My Feed\`). macOS는 앱을 휴지통에 넣어도 이 폴더를 지우지 않으므로, 완전히 삭제하려면 앱과 이 폴더를 함께 지우면 됩니다.

## 처음 설정
**피드 주소**에 RSS 또는 Atom 피드 주소를 붙여 넣고 **구독하기**를 누릅니다. 대부분의 뉴스 사이트와 블로그는 "RSS"라는 링크로 피드를 안내하니, 그 링크의 주소를 복사하면 됩니다.

화면은 시스템 언어로 시작하고, 지원하지 않는 언어면 영어로 시작합니다. 표시 언어와 화면 테마(시스템 설정, 라이트, 다크)는 **설정**에서 바꿀 수 있습니다. 한국어와 영어는 직접 썼고, 나머지 언어는 AI로 번역해 원어민 검수를 거치지 않았습니다. 백엔드 오류 메시지와 데스크톱 앱의 알림 창은 영어로 나옵니다.

## 사용 방법
- **내 피드**에는 모든 피드의 글이 최신순으로 나옵니다. 목록 위의 버튼으로 피드 하나의 글만 볼 수 있습니다. **새로고침**을 누르면 모든 피드를 다시 읽어 최신 목록(피드당 최대 100개)으로 바꿉니다. 읽지 못한 피드는 이전 목록을 유지하고 이름을 알려 줍니다.
- 글을 누르면 앱 안에서 열립니다. 원문을 가져올 수 없으면 피드에 있던 요약을 보여 줍니다.
- **페이지 넘기기**: 화면 왼쪽이나 오른쪽 끝(각 5분의 1)을 누르거나, 좌우 방향키·Page Up/Down·스페이스 키를 씁니다. 화면 가운데를 누르면 아래쪽 메뉴가 나타나거나 사라집니다. 메뉴에는 쪽 번호, 이전·다음 버튼과 아래 기능이 있습니다.
    - **보기 설정**: 배경색(화이트, 세피아, 민트, 포레스트, 그레이, 다크), 글자 크기, 줄 간격, 위아래·좌우 여백, 한 페이지/두 페이지 보기. 두 페이지 보기는 창 너비가 720픽셀 이상일 때 적용되고, 고른 값은 저장됩니다.
    - **Markdown으로 저장**: 글의 본문을 날짜와 제목으로 이름 붙인 `.md` 파일로 저장합니다.
    - **닫기**: Esc 키로도 닫을 수 있습니다.
- 글을 처음 열면 사용법 안내가 나옵니다. 끝까지 보거나 "다시 보지 않기"를 고르면 다시 나오지 않습니다.
- **설정**의 구독 목록에서 **구독 해제**를 할 수 있습니다.
